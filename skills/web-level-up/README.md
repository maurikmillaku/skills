# web-level-up

An intelligent, self-contained agent skill that elevates any existing website to world-class software standards.

Most websites look fine on a laptop, but feel cheap, generic, or broken when evaluated closely. Buttons feel unresponsive, hovers stick on touchscreens, form inputs trigger jarring mobile zoom, typography is loose, and decorative AI boilerplate clutters the interface.

`web-level-up` is not a passive CSS linter. It is an intelligent design engineering system that gives your AI agent the taste, standards, and code needed to perform a **complete, noticeable craft transformation** across six master pillars:

1. **Architectural Site, Domain & Asset Intelligence**:
   - Analyzes the domain and layout anatomy before writing code.
   - Preserves and elevates authentic photography with optical framing, subtle hover zoom, and live status badges.
   - Replaces template icons with bespoke geometric vector SVG marks.

2. **Taste, Optical Typography & Color Calibration**:
   - Enforces the Rule of 5 Words (hero titles never exceed 5 bold, punchy words).
   - Calibrates negative tracking (-0.035em) and tight leading (1.08) for display headlines.
   - Eradicates muddy purples and garish gradients into calibrated Obsidian Black and Paper Light modes.
   - Purges artificial AI sparkles, fake milestone tags, and decorative clutter.

3. **Signature High-Craft Feature Suite**:
   - **Dual Light/Dark Mode**: Zero-flash persistence with tactile floating theme toggle.
   - **Global Command+K Action Palette**: Instant keyboard shortcuts for section navigation, theme toggling, and actions.
   - **Apple Liquid Glass Materials**: Translucent surfaces, hairline borders, and inner specular bevel highlights.
   - **Apple-Style Segmented Pill Controls**: Smooth sliding tab selectors for pricing tiers and category filters.
   - **Specular Ambient Cursor Spotlight**: Desktop cursor light glare that tracks pointer coordinates across interactive cards.

4. **Apple Fluid Motion & Emil Kowalski Physics**:
   - Instant tactile button compression (scale 0.96) on pointer-down.
   - Physical spring settle curves (cubic-bezier 0.16, 1, 0.3, 1).
   - Interruptible spring dialogs and smooth accordion height transitions.

5. **Platform Touch & Zero-Defect Hygiene**:
   - Eradicates the 300ms tap delay and tap highlight flashes.
   - Eliminates sticky hover states on mobile using capability media queries.
   - Enforces the 16px minimum font rule to prevent iOS Safari auto-zoom.
   - Upgrades viewport sizing to `100svh` and `100dvh` to respect dynamic mobile browser bars.
   - Enforces punctuation hygiene: zero em-dashes and zero directional UI arrows.

6. **Autonomous Visual & Interactive Self-Audit Protocol**:
   - Never stop at compilation: `npm run build` only checks syntax, not visual layout or touch mechanics.
   - Inspects floating badges for overflow clipping from parent card boundaries.
   - Interactively tests every button, tab, modal, theme toggle, and accordion before handoff.
   - Self-corrects any discovered flaws autonomously without waiting for user feedback.

## Installation

Install using the skills CLI:

```bash
npx skills add maurikmillaku/skills --skill web-level-up
```

Or copy `SKILL.md` directly into your project at `.agents/skills/web-level-up/SKILL.md`.
