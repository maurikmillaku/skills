# web-level-up

An intelligent, self-contained agent skill that elevates any existing website to world-class software standards.

Most websites look fine on a laptop, but feel cheap, generic, or broken when evaluated closely. Buttons feel unresponsive, hovers stick on touchscreens, form inputs trigger jarring mobile zoom, typography is loose, and decorative AI boilerplate clutters the interface.

`web-level-up` is not a passive CSS linter. It is an intelligent design engineering system that gives your AI agent the taste, standards, and code needed to perform a **complete, noticeable craft transformation** across three unified phases:

1. **Taste & Architecture Audit**:
   - Purges artificial AI badges, fake milestone chips, and decorative clutter.
   - Rewrites verbose, academic headlines into punchy, confident Apple-grade typography.
   - Overhauls muddy purples and garish gradients into calibrated obsidian dark mode and crisp paper light mode.
   - Replaces synthetic stock imagery with authentic photography or live interactive previews.

2. **Signature High-Craft Feature Suite**:
   - **Dual Light/Dark Mode**: Complete with zero-flash persistence and a tactile floating theme toggle.
   - **Apple-Style Segmented Pill Controls**: Smooth sliding tab selectors for pricing tiers or category filters.
   - **Translucent Floating Glass Chrome**: Blurred top navigation (`backdrop-filter: blur(20px)`) with blur quarantine preserving 60–120 FPS mobile scrolling.
   - **Ambient Cursor Spotlight**: Desktop cursor light glare that tracks pointer coordinates across interactive cards.
   - **Spring Modals & Dialogs**: Centered dialogs entering via physical spring physics (`scale(0.96) -> scale(1)`) with backdrop dimming and Escape key dismiss.

3. **Platform & Touch Defect Eradication**:
   - Eradicates the 300ms tap delay and tap highlight flashes.
   - Eliminates sticky hover states on mobile using capability media queries.
   - Enforces the 16px minimum font rule to prevent iOS Safari auto-zoom.
   - Upgrades viewport sizing to `100svh` and `100dvh` to respect dynamic mobile browser bars.
   - Implements display notch safe areas (`env(safe-area-inset-*)`).
   - Enforces punctuation hygiene: zero em-dashes (`—`), zero UI directional arrows (`→`), and direct, grounded copy.

## Installation

Install using the skills CLI:

```bash
npx skills add maurikmillaku/skills --skill web-level-up
```

Or copy `SKILL.md` directly into your project at `.agents/skills/web-level-up/SKILL.md`.
