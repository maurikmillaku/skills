# Maurik Millaku Skills

A curated catalog of agent skills designed to elevate websites and applications to world-class software standards.

You do not need a dozen fragmented tools or complex rewrites. These skills are self-contained and give your AI agent the exact principles, diagnostic checks, physics formulas, and production code needed to turn existing projects into fast, tactile, and rock-solid software.

---

## Skills Catalog

### `web-level-up`
Elevates any existing website or web app to world-class software standards across six self-contained pillars:
- **Pillar 1: Architectural Site, Domain & Asset Intelligence**: Domain-specific analysis, authentic photography elevation (optical framing, hover physics, live liquid glass badges), and bespoke geometric vector SVG marks replacing template icons.
- **Pillar 2: Taste, Optical Typography & Color Calibration**: Rule of 5 Words (punchy titles under 5 words, negative optical tracking, tight leading), obsidian black base, crisp paper light mode, and complete purging of AI sparkles and boilerplate.
- **Pillar 3: Signature High-Craft Feature Suite**: Dual Dark/Light mode theme architecture with sticky toggle, global Command+K action palette (`⌘K`), Apple Liquid Glass materials with inner specular bevels, segmented pill controls, and specular ambient cursor spotlights.
- **Pillar 4: Apple Fluid Motion & Emil Kowalski Physics**: Instant pointer-down active compression (`scale(0.96)`), critically damped spring settle curves (`0.16, 1, 0.3, 1`), interruptible spring dialogs, and smooth accordion transitions.
- **Pillar 5: Platform Touch & Zero-Defect Hygiene**: 16px touch input rule (eradicating iOS Safari auto-zoom), dynamic viewport units (`100svh`/`100dvh`), gated hover capability queries, zero em-dashes, and zero directional UI arrows.
- **Pillar 6: Autonomous Visual & Interactive Self-Audit Protocol**: Mandatory post-build inspection loop. The agent must never stop at compilation: it visually checks floating badges for overflow slicing, tests all buttons, tabs, modals, and themes, and self-corrects any discovered defects before presenting to the user.
- **Plain, Understandable Handoff**: Every AI agent using this skill reports back in plain, everyday human language (in English or the user's spoken language) without technical code jargon or clutter.

## Installation

Install all skills at once:
```bash
npx skills add maurikmillaku/skills --all
```

Or install an individual skill:
```bash
npx skills add maurikmillaku/skills --skill web-level-up
```
